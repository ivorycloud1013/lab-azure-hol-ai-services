# What the harness lab needs on top of python/requirements.txt.
#
# Only step3_eval.py --judge evaluation needs anything from here. Steps 0 to 2 and
# step 3's default judge run on what the lab already installs, which is deliberate:
# the metrics that carry the lesson — hit, confident-wrong answers, harness rejections,
# wasted rejections, tokens, tool errors — are all deterministic and cost nothing.
#
#   pip install -r requirements.txt                      # steps 0-3, ungraded
#   pip install -r requirements.txt -r harness/requirements.txt   # adds graded scores
#
# This file is separate because python/requirements.txt says on its first line that it
# ships in the code-deploy ZIP. Everything listed there lands inside the hosted agent's
# container, and azure-ai-evaluation drags in pandas, nltk, msrest and Jinja2 — hundreds
# of megabytes the container has no use for.
#
# 1.18.3 is the first release that no longer depends on promptflow; the evaluators carry
# their own prompty runtime now. Older versions pull the whole promptflow stack in, which
# is where this package used to fail to install.
azure-ai-evaluation>=1.18.3
